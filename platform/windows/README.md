# Windows (not implemented)

Planned for Phase 14, only after the Linux version is stable.

- UI: a native always-on-top overlay window (Windows allows positioning and
  stacking, unlike GNOME Wayland).
- Reuse: `selawi-core` (event model and engine) and the event protocol.
- Adapters to write: Windows notifications, media sessions
  (GlobalSystemMediaTransportControls), audio, Bluetooth, system events.
